## LiminalNet

[LiminalNet](https://github.com/RZU-IT/LiminalNet) est un outil de surveillance réseau en terminal pour Windows et Linux, développé en Rust. Trafic, connexions, filtres et captures dans une interface au clavier.

Le projet est expérimental. Les tests effectués et les limites par plateforme sont consignés dans le [rapport de validation](https://github.com/RZU-IT/LiminalNet/blob/main/docs/validation.md).
